# Security policy (DRAFT)

- Report vulnerabilities privately as described at https://olip.ai/security/ (currently the sponsor's published contact address with "OLIP security" in the subject; a dedicated address is not set up yet).
- Acknowledge within 3 business days; triage within 10; coordinated disclosure within 90 days or sooner by agreement.
- Spec-level flaws (for example a consent bypass) get an advisory, a conformance test and a patched spec version.
- Safe harbor for good-faith research against mock or sandbox endpoints only. Never test against production endpoints with real data, and never send a real contact request to test.
