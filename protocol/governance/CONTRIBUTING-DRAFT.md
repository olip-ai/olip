# Contributing (DRAFT)

There is no public repository or issue tracker yet. Send feedback as described at https://olip.ai/community/. Rules once a public repository exists:
- Open an issue first for any normative change. Use the template: problem, proposal, compatibility impact, test plan.
- Every normative change ships with schema updates, a conformance test and an example.
- Never add real client, lawyer or firm data. Fictional data only (`.test` domains, `TEST-` license numbers).
- Sign off commits (DCO).
- Code of conduct: Contributor Covenant 2.1.
- Security issues: do not open public issues; see `SECURITY-POLICY-DRAFT.md`.
