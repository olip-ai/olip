# Implementations

Everything listed as available can be downloaded and run locally today from the [OLIP draft kit](pathname:///downloads/olip-0.2-draft-kit.zip). Nothing is hosted for public testing; to see the flow without installing anything, use the [browser simulation](/try/). All data is fictional.

## Listing your implementation

Any implementation can be listed here on equal terms, free: a name, a link, the profiles it supports, and a dated self-test result from the public suite.

To be listed, follow [Publish your conformance results](/docs/contributing/publish-results/). The sponsor's own products are listed on the same terms and are never counted as independent.
