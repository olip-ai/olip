# Security policy

**Report privately.** Email notices@esqcopilot.com with "OLIP security" in the subject (the sponsor's published address; a dedicated OLIP address does not exist yet). You may also use "Report a vulnerability" on this repository's Security tab (GitHub private vulnerability reporting). **Never open a public issue, pull request or discussion about an unfixed problem.**

Include: the affected file or section and version (0.1 or 0.2), steps to reproduce against the **local mock endpoint with fictional data**, and the impact you expect.

- Acknowledgment target: 3 business days. Triage target: 10 business days.
- Coordinated disclosure within 90 days, or sooner by agreement.
- Specification-level flaws get a public advisory, a new conformance test and a patched spec version.
- Safe harbor for good-faith research against the local mock endpoints and fictional data only. Never test against a production endpoint with real data, and never send a real contact request to a real lawyer.

Review scope and priority areas: https://olip.ai/docs/contributing/security-review-scope/

**Status:** no independent security review of OLIP or its reference code has been done yet.
