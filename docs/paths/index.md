# Pick your path

OLIP has three kinds of users. Each path below is short, links to the full technical pages, and pins the version it uses. None of them needs an account with the sponsor or any company.

| You are | You want to | Start here | Time |
|---|---|---|---|
| **AI agent developer** | Let a person find a lawyer and send one approved request from your agent, over MCP or HTTPS | [Path for AI agent developers](/docs/paths/ai-agent-developers/) | 5 min read-only, 30 min full handoff |
| **Law firm** | Publish who you are, what you accept and how to reach you; receive only what the person approved | [Path for law firms](/docs/paths/law-firms/) | 15 min read |
| **Legal software vendor** | Add OLIP to an intake or practice-management product and test it with the public suite | [Path for legal software vendors](/docs/paths/legal-tech-vendors/) | 1 to 3 days for a first endpoint |

Not sure yet? [Try OLIP in your browser](/try/) first. It is a fictional simulation and contacts no one.

## Which version?

Build against **OLIP 0.1** (the base) and add the **0.2 additions** only if you need them. 0.2 changes nothing in 0.1; every 0.2 feature is optional. See [Versions and compatibility](/spec/versions/).

## What OLIP never does, on any path

- It does not certify a license, a lawyer's competence or an outcome.
- It does not create an attorney-client relationship. Delivered, acknowledged and responded are not acceptance.
- It has no paid ranking. Discovery order is disclosed and `paid_influence` is always `false`.
- Technical conformance is not legal or regulatory clearance.
